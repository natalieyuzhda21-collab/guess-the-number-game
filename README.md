# Игра: Угадай число (Guess the Number)

Это мой первый учебный проект на Python для портфолио. Консольная игра, в которой пользователь должен угадать случайное число, загаданное компьютером.

## 🚀 Функционал
- Генерация случайного числа от 1 до 100.
- Подсчет количества попыток.
- Обработка ошибок (если пользователь ввел буквы вместо цифр).

## 🛠️ Технологии
- Python 3.x
- Модуль `random`
